App：课程表
平台：iOS 17+
Bundle ID（待发布方替换）：com.codex.coursetable.app
版本：1.0.0 (1)

核心功能：
1. 选择本地图片或相册图片，识别课程表内容。
2. OCR 结果进入可编辑确认页，确认后保存课程。
3. 支持普通节次和自定义起止时间的不规则课程。
4. 支持用户主动把课程及提醒导入 Apple 系统日历。

注意：本项目当前是 iOS 工程，没有 Android APK，因此不能提供 Android 包名或 APK 的 MD5/SHA1/SHA256。签名、证书、Team ID、实名资料请由发布方安全配置，不要提交到公开 GitHub。
